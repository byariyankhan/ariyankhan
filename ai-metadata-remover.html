What Gets Removed

Every hidden tag that says "made with AI"

Modern image files carry far more than pixels. Generators, editors, phones and cameras all stash data in side blocks of the file. This tool parses the container, keeps only what the decoder needs to draw the picture, and drops everything else.

C2PA Content Credentials

The cryptographically signed provenance manifest (stored in JUMBF / APP11 in JPEG, a caBX chunk in PNG, a C2PA chunk in WebP) that ChatGPT, DALL·E, Adobe Firefly, Photoshop, Microsoft Designer and newer cameras write. This is the main signal behind “AI info” labels.

XMP & IPTC

Adobe's XMP packet and the IPTC/Photoshop resource block. Includes the DigitalSourceType = trainedAlgorithmicMedia tag, creator tool, edit history, Midjourney prompt text, keywords and copyright fields.

EXIF, GPS & software tags

Camera make and model, serial number, exact GPS coordinates, capture time, and the “Software” field that editors and some generators fill in. Optional: keep it for real photos.

Stable Diffusion prompts

PNG tEXt, iTXt and zTXt chunks — the parameters block from Automatic1111 and Forge, the prompt / workflow JSON from ComfyUI, Fooocus and InvokeAI metadata, NovelAI comments.

Hidden extra images

MPF multi-picture indexes, embedded thumbnails and any bytes appended after the end-of-image marker — where depth maps, motion-photo video and leftover editor data hide.

Comments & timestamps

JPEG COM segments, PNG tIME, Adobe “Ducky” and FlashPix blocks, and unknown application segments. Colour profiles (ICC) and the Adobe colour-transform marker are kept on purpose so your colours render exactly as before.

How It Works

Three steps, zero uploads

  1. Drop, paste or browsePick one image or fifty. The file is read into your browser's memory with the standard File API — the page never contacts a server.
  2. The container is rewrittenThe tool walks the JPEG segments, PNG chunks or WebP RIFF chunks, copies the compressed pixel data untouched, and skips every metadata block. It also runs a signature scan so the report can name the generator it found.
  3. Download the clean fileYou get a new file with -clean added to the name, usually a little smaller, visually identical. Reload the page and everything is gone from memory.

Why not just re-save the image? Re-encoding a JPEG in Photoshop or a canvas-based tool costs you quality on every pass and can quietly write fresh metadata back in (Photoshop and Lightroom now add Content Credentials by default). Rewriting only the container is the clean way: identical pixels, no new tags.

What platforms read

Instagram, Facebook and Threads decide on the “AI info” label mostly from C2PA and IPTC metadata. LinkedIn shows a Content Credentials icon when it finds a C2PA manifest. TikTok and Pinterest auto-label uploads carrying Content Credentials. YouTube reads C2PA to show a “captured with a camera” badge on eligible videos and separately requires creators to disclose realistic altered media. All of those systems look at the file's metadata first — which is exactly what this tool rewrites.

A normal week means dozens of thumbnails, B-roll stills and map textures going through Photoshop, and more and more of them touch a generative tool somewhere — a background extended with generative fill, a stock photo upscaled, a texture cleaned up. Then a client posts a completely real photo of themselves to Instagram and it gets an “AI info” badge because the sky was extended by a few pixels.

The tools I found for this were either paid, capped at three images a day, or — worse — uploaded the file to someone's server first. Thumbnail files for unreleased videos are confidential. So I wrote a small parser that runs in the browser, and put it here for anyone who needs it.

Good reasons to strip metadata

  • Privacy: phone photos carry exact GPS coordinates, device serial numbers and timestamps. Strip them before posting a house, a kid or a workplace.
  • Portfolio hygiene: your Stable Diffusion prompt, seed and model hash don't belong in a client deliverable or a print-on-demand upload.
  • False-positive labels: a real photograph retouched with a generative tool shouldn't be presented as fully synthetic.
  • Smaller files: a single Content Credentials manifest can be 30–100 KB. Stripping it speeds up every page the image sits on.
  • Sanitised screenshots and assets: remove editor history and comment blocks before sharing files with third parties.

Honest Limits

What a metadata remover cannot do

  • It cannot remove pixel watermarks. Google SynthID, Meta's invisible marker and similar techniques are embedded in the image content itself. They survive metadata stripping, cropping and mild compression by design. This tool does not attempt to defeat them.
  • It cannot fool pixel-based AI detectors. Classifiers that judge texture, noise and frequency patterns don't read tags at all.
  • It cannot control platform policy. Meta, TikTok, LinkedIn and YouTube can add new signals, run their own detection, or ask you directly. Treat the result as “metadata-clean”, not “undetectable”.
  • It cannot un-sign a video. This page handles still images only. C2PA in MP4 is a different container and a different tool.

Use it responsibly

Metadata is yours to remove; the obligation to be honest about synthetic media isn't removed with it. YouTube's altered-content disclosure, Meta's policy on realistic AI content, and the EU AI Act's transparency rules apply regardless of what the file's tags say. Clean your files for privacy, quality and accuracy — and disclose AI-generated content where the platform or the law asks you to.
