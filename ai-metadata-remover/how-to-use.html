How to use AI Metadata Remover

How to clean a file, what the report means, what exactly gets removed, and how to confirm the result with other tools.

1. Clean an image

  1. Open AI Metadata Remover.
  2. Add images in any of three ways: drag them onto the drop area, click it (or focus it and press Enter) to browse, or copy an image and paste it anywhere on the page with Ctrl+V or ⌘V.
  3. Each file is processed straight away and gets its own card with a Download button. With several files, Download all saves them one after another.
  4. Press Clear to empty the list and free the memory, or simply close the tab.

Clean files keep their original name with -clean added, so thumbnail.png becomes thumbnail-clean.png and you never overwrite the original.

2. Choose a mode

  • Remove everything (recommended): C2PA, XMP, IPTC, EXIF including GPS, comments, PNG text chunks and any hidden trailing data. The colour profile is kept, so colours do not shift.
  • Keep camera EXIF: removes the AI and provenance blocks but leaves the EXIF block with camera model, lens, exposure and date. Use it only for real photographs where that information matters. EXIF can itself hold GPS coordinates and a software name, and the report warns you if the kept block still mentions a generator.

The mode applies to files you add after choosing it. To re-run a file in the other mode, switch and add it again.

3. Read the report

Every card shows the file’s size before and after, then:

  • A red badge naming a generator or tool (for example ChatGPT, Adobe Firefly or Stable Diffusion) when its signature was found in the metadata.
  • A grey badge, “No known AI signature found”, when the file held ordinary metadata but nothing from a known generator. That metadata is still removed.
  • A green badge, “Already clean”, when the file had no metadata to remove.
  • A list of removed blocks with their sizes, so you can see exactly what was in the file. In Keep camera EXIF mode, a second list shows what was kept.
  • Notes and warnings, for example when a format had to be converted, or when a kept EXIF block still names an AI tool.

5. What gets removed

C2PA Content Credentials

The signed provenance manifest (JUMBF/APP11 in JPEG, a caBX chunk in PNG, a C2PA chunk in WebP) written by ChatGPT, DALL·E, Adobe Firefly, Photoshop, Microsoft Designer and newer cameras. It is the main signal behind “AI info” labels.

XMP and IPTC

Adobe’s XMP packet and the IPTC/Photoshop block, including DigitalSourceType = trainedAlgorithmicMedia, the creator tool, edit history, Midjourney prompt text, keywords and copyright fields.

EXIF, GPS and software tags

Camera make, model and serial number, exact GPS coordinates, capture time and the “Software” field. Optional: keep it for real photos.

Stable Diffusion prompts

PNG tEXt, iTXt and zTXt chunks: the parameters block from Automatic1111 and Forge, the prompt and workflow JSON from ComfyUI, and Fooocus, InvokeAI and NovelAI metadata.

Hidden extra images

Multi-picture indexes, embedded thumbnails and bytes appended after the end of the image, where depth maps, motion-photo video and leftover editor data hide.

Comments and timestamps

JPEG comment segments, PNG tIME, Adobe “Ducky” and FlashPix blocks. The colour profile (ICC) and Adobe’s colour-transform marker are kept on purpose.

Why not just re-save the image? Re-encoding a JPEG loses quality on every pass, and editors such as Photoshop and Lightroom can write fresh Content Credentials back in. Rewriting only the file’s container gives identical pixels and no new tags.

7. Check the result yourself

You do not have to take the report’s word for it. Any of these will show what is left in the clean file:

  • Content Credentials: upload the clean file to the Content Authenticity Initiative’s free Verify site (contentcredentials.org/verify). A cleaned file shows no credentials.
  • ExifTool: run exiftool -a -G1 file-clean.jpg and compare it with the original. Only basic file and image-size fields should remain.
  • Windows: right-click the file, Properties, Details. The camera, GPS and program fields should be empty.
  • macOS: open it in Preview, Tools, Show Inspector. The EXIF, GPS and IPTC tabs should be gone.

8. Four everyday uses

Phone photos before you post them

Phone pictures carry the exact GPS position they were taken at. Clean photos of a home, a child’s school or a workplace in Remove everything mode before sharing them.

Thumbnails and client deliverables

Files that went through Photoshop’s generative tools can carry Content Credentials and edit history. Clean the final export so that a client or a platform gets the picture, not your working history.

Stable Diffusion work for a portfolio or print shop

A PNG straight out of A1111 or ComfyUI contains your full prompt, seed and model. Clean it before uploading to a print-on-demand shop or sending it to a buyer.

Real photos wrongly labelled as AI

A real photograph with a small generative retouch can be labelled as if it were fully synthetic. Clean it, and disclose the edit yourself where the platform asks you to. The About page explains why that matters.
