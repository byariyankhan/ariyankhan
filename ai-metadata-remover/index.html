Three steps, no uploads

  1. Drop, paste or browsePick one image or fifty. Each file is read into your browser’s memory; the page never sends it anywhere.
  2. The file is rewrittenThe tool walks the file’s blocks, copies the compressed picture untouched and leaves every metadata block out. A report lists what was removed and which generator left a signature.
  3. Download the clean copyYou get a new file ending in -clean, visually identical and usually smaller. Close the tab and it is gone from memory.
