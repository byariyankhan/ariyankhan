About AI Image Checker & FAQ

A quick, private way to see what an image file says about how it was made.

What it is

Every image file can carry hidden information next to the picture: the camera or app that made it, when and where, and more and more often a record saying it was generated or edited with AI. AI Image Checker opens the file in your browser, reads all of it, and tells you in plain words what it found.

How it works

It reads the file’s structure, the segments of a JPEG or the chunks of a PNG or WebP, and looks at each metadata block: EXIF, XMP, IPTC, PNG text and C2PA Content Credentials. It then searches them for the signatures that known AI generators leave. It uses the same parser as AI Metadata Remover, so the two tools always agree on what is in a file.

What it deliberately does not do

  • It does not guess from the pixels. It only reports what the file says about itself, so it never labels a photo as AI just because of how it looks.
  • It does not upload or store anything.
  • It does not read pixel watermarks such as SynthID.

Questions

Is AI Image Checker free?

Yes. There is no sign-up and no limit on how many images you check.

Are my images uploaded?

No. Each file is read by JavaScript inside your browser tab and never sent anywhere. You can load the page, go offline, and it still works.

Can it prove that an image is AI-generated?

It can show what the file’s metadata says. If the metadata names an AI generator, that is strong evidence. But metadata can be removed or edited, so a file with none proves nothing either way.

Which AI tools does it recognise?

ChatGPT and DALL·E, Google Gemini and Imagen, Adobe Firefly, Midjourney, Microsoft Designer and Bing Image Creator, Stable Diffusion tools such as Automatic1111, ComfyUI, Fooocus and InvokeAI, and others including Leonardo, Ideogram and Canva.

Why does a real photo show Content Credentials?

C2PA is not only for AI. Some cameras and editing apps, such as Photoshop and Lightroom, add Content Credentials to record how a file was captured or edited.

Why does an AI image show nothing?

The metadata was probably removed: by a screenshot, by re-saving, by a platform that strips it on upload, or deliberately.

Does it detect SynthID?

No. SynthID is a watermark inside the pixels, not metadata, and can only be checked with Google’s own tools.

Which formats work?

JPG, PNG and WebP, up to 80 MB each.
