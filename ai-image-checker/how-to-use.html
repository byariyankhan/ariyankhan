How to use AI Image Checker

How to check a file, what the three kinds of result mean, what each line of the report tells you, and where metadata stops being evidence.

  2. The three results
  3. What each line means

1. Check an image

  1. Open AI Image Checker.
  2. Press Check images and choose one or more files, drag them onto it, or copy an image and paste it anywhere on the page.
  3. Each image gets a card with a verdict at the top and, underneath, everything the file says about itself. Clear empties the list.

JPG, PNG and WebP files can be read. Other formats have to be converted first. Screenshots, and images saved from most social networks, usually carry no metadata at all, because the platform removes it on upload.

2. The three results

ResultWhat it means
AI signs foundThe metadata names an AI generator, or carries the IPTC tag for AI-generated media. The card says which one.
Content Credentials foundThe file has a signed C2PA record of how it was made or edited, but no known AI generator is named in it. Cameras and editors such as Photoshop write these too.
No AI metadata foundNothing in the file points to an AI tool. The file may be a real photo, or its metadata may have been removed.

3. What each line means

  • Content Credentials (C2PA): a signed record, added by apps such as ChatGPT, Adobe Firefly, Photoshop and Microsoft Designer, and by some newer cameras. Where the record names the app that wrote it, the card shows that name.
  • Digital source type: an IPTC field. trainedAlgorithmicMedia means the image was made by an AI model; compositeWithTrainedAlgorithmicMedia means AI was used for part of it.
  • Created with and Software: the program that last saved the file, such as a camera’s firmware, Photoshop or an AI tool.
  • Camera, Date taken and Artist: EXIF fields written by cameras and phones. AI generators rarely fill them in.
  • GPS location: the coordinates where a photo was taken. If you see this on your own photo, anyone you send the file to can see it too.
  • AI prompt / settings: the prompt, seed and model that Stable Diffusion front-ends such as Automatic1111 and ComfyUI save in PNG files.
  • Metadata blocks: the full list of hidden sections found in the file, from EXIF and XMP to embedded thumbnails.

4. What metadata cannot tell you

Metadata is written by software and can be removed, changed or faked by software. Treat the result as what the file says about itself, not as a verdict on the picture:

  • No metadata is not proof of a real photo. Re-saving, screenshotting or uploading to most platforms strips it.
  • Pixel watermarks are not metadata. Google’s SynthID and similar marks live inside the image and need the maker’s own detector.
  • AI detectors that judge the pixels work differently and have their own error rates. This tool does not guess from how an image looks.

For an important image, combine several checks: the metadata, a reverse image search to find where it first appeared, and the source that published it.

5. What to do next

If you want the hidden data gone, for privacy or before publishing, use AI Metadata Remover: it removes every block the checker lists, without touching the pixels. And if you publish AI-generated images, check what the platform asks you to disclose.
